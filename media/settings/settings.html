Prompt Studio Settings

Default note view

Which view a note opens in when you click it in the Vault view or on the canvas. The other view stays on the row's hover button and in the right-click menu.

Project vault location

Which folder holds this project's notes. The choice is remembered for this workspace, so another project can point somewhere else.

Global vault location

Which folder holds the notes every project shares. The Vault view swaps over to them with the globe button in its title bar.
