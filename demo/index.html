Notes you can still open in ten years

Every Aurora note is a plain markdown file on your own disk, readable by any text editor you already have.

Get started Read the docs

What you get

  • Plain files on disk

    Aurora writes each note as a markdown file in a folder you choose, with no database in the way.

  • Works offline

    Everything runs on your machine, and the app opens and saves the same whether or not you have a network.

  • Links between notes

    Type two square brackets to link one note to another, then follow the backlinks to see what points here.
