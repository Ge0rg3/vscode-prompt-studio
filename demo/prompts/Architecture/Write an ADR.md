# Write an ADR

Write up this decision as an ADR. The decision is already made. Do not argue for a different one.

Decision: {{decision}}
Alternatives we looked at: {{alternatives}}

Use these sections and nothing else:

- **Context** - what was going on that forced a choice. Constraints we actually had, not ideal ones.
- **Decision** - one paragraph, present tense, "we will ...".
- **Consequences** - what gets easier, and what gets worse. Include the things we will regret. If it
  locks us into a vendor or a data shape, say so plainly.
- **Alternatives considered** - one short paragraph each, ending with why we did not pick it.

Keep it to a page. No preamble, no summary at the end.
